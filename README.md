# Portal de Viagens

Projeto desenvolvido com Next.js para a atividade da EBAC.

## Funcionalidades

- Página inicial
- Listagem de destinos turísticos
- Página dinâmica para detalhes dos destinos
- Navegação entre páginas
- Componentes reutilizáveis
- Estilização com CSS Modules

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- CSS Modules
